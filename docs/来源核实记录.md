# 来源核实记录

这本指南的信用全押在一件事上：**「来源」栏写的东西，读者点进去能看到那句原文**。这份记录就是那条链路的外账——每条 A 级条目在这里有一行，写明我们**实际抓取过**的页面、抓取日期，以及页面上的原句。

三条规矩：

1. **只记抓到的，不记记忆的。** 没在页面上亲眼看到的条号、比例、金额，一律不进正文；进了正文的必须能在本页找到对应行。
2. **摘录必须是逐字。** 媒体转述、博客总结、模型记忆都不算来源。英文文献抄原句，法条抄条款全文。
3. **核不上就降级，不硬撑。** 来源栏写「待核实」不是失败，写一个想当然的条号才是。

## 第 8 节 被裁、离职与欠薪

### 8-2 「月工资」有上限，也有下限

| 项 | 内容 |
| --- | --- |
| 断言 | 算经济补偿用的月工资是**应得工资**（含奖金、津贴），不是实发工资；低于当地最低工资标准的按最低工资算；工作不满 12 个月的按实际月数算平均 |
| 出处 | 《中华人民共和国劳动合同法实施条例》（国务院令第 535 号，2008-09-18 公布）第二十七条，共 3 款 |
| 抓取页 | <https://fgk.chinatax.gov.cn/zcfgk/c100010/c5194419/content.html>（国家税务总局政策法规库全文页） |
| 访问日期 | 2026-09-20 |
| 逐字摘录 | 「劳动合同法第四十七条规定的经济补偿的月工资按照劳动者应得工资计算，包括计时工资或者计件工资以及奖金、津贴和补贴等货币性收入。劳动者在劳动合同解除或者终止前12个月的平均工资低于当地最低工资标准的，按照当地最低工资标准计算。劳动者工作不满12个月的，按照实际工作的月数计算平均工资。」 |
| 附带确认 | 该条首句直接点名「劳动合同法第四十七条」，因此 **经济补偿的计算标准确为《劳动合同法》第四十七条**，本条引用可交叉对上 |
| 尚未核实 | 第四十七条第二款里的「三倍封顶」与「年限最高不超过十二年」须拿到《劳动合同法》本体全文逐字核对；各城市的社平工资三倍数额每年由地方公布，必须逐城市查当年文件，正文里保持「待核实」 |

### 8-3 劳动仲裁不收费，时效一年——但你可以让它重新起算

| 项 | 内容 |
| --- | --- |
| 断言 | 仲裁不收申请费；时效一年自知道或应当知道之日起算；**主张权利 / 请求救济 / 对方同意履行 → 中断并重新计算**；在职期间欠薪不受一年限制，终止劳动关系后起一年内提出 |
| 出处 | 《中华人民共和国劳动争议调解仲裁法》（2007-12-29 第十届全国人大常委会第三十一次会议通过，2008-05-01 施行）第二十七条、第五十三条 |
| 抓取页 | <http://www.npc.gov.cn/c2986/c4488/201905/t20190523_48437.html>（全国人大网）；<http://gongbao.court.gov.cn/Details/997e66171cf55d219c613ec18dc370.html>（最高人民法院公报网）；<https://rlsbj.cq.gov.cn/zwgk_182/fdzdgknr/lzyj/falv/202103/t20210305_8968497.html>（重庆市人社局） |
| 访问日期 | 2026-09-20 |
| 逐字摘录 | 「第二十七条 劳动争议申请仲裁的时效期间为一年。仲裁时效期间从当事人知道或者应当知道其权利被侵害之日起计算。前款规定的仲裁时效，因当事人一方向对方当事人主张权利，或者向有关部门请求权利救济，或者对方当事人同意履行义务而中断。从中断时起，仲裁时效期间重新计算。因不可抗力或者有其他正当理由，当事人不能在本条第一款规定的仲裁时效期间申请仲裁的，仲裁时效中止。从中止时效的原因消除之日起，仲裁时效期间继续计算。劳动关系存续期间因拖欠劳动报酬发生争议的，劳动者申请仲裁不受本条第一款规定的仲裁时效期间的限制；但是，劳动关系终止的，应当自劳动关系终止之日起一年内提出。」「第五十三条 劳动争议仲裁不收费。劳动争议仲裁委员会的经费由财政予以保障。」 |

| 断言（费用） | 劳动争议案件受理费每件 10 元；追索劳动报酬的案件**可以**不预交案件受理费 |
| 出处（费用） | 《诉讼费用交纳办法》（国务院令第 481 号，2006-12-19 公布，2007-04-01 施行）第十三条第（四）项、第二十条第一款 |
| 抓取页（费用） | <https://www.gov.cn/zhengce/zhengceku/2008-03/28/content_6929.htm>（中国政府网·政策文件库）；同文另见 <https://www.gov.cn/gongbao/content/2007/content_512694.htm>、最高法公报网、<https://fy.huaian.gov.cn/col/11909_166277/art/202009/1601023850486EJ6zYbvU.html>（淮安市中级人民法院） |
| 访问日期（费用） | 2026-09-20 |
| 逐字摘录（费用） | 「（四）劳动争议案件每件交纳10元。」「第二十条 案件受理费由原告、有独立请求权的第三人、上诉人预交。被告提起反诉，依照本办法规定需要交纳案件受理费的，由被告预交。追索劳动报酬的案件可以不预交案件受理费。」 |
| 编者改正 | 本条草稿原有三处**想当然的简化**，均已按原文改正，记录在此以免复发：① 「不受一年限制」→ 原文是「不受**本条第一款规定的**仲裁时效期间的限制」，且主语是「劳动者申请仲裁」；② 「仲裁经费由财政予以保障」→ 原文是「**劳动争议仲裁委员会**的经费」；③ 原以为「劳动争议案件不预交案件受理费」——**该说法在整部办法五十六条里不存在**，「劳动争议」全文只出现 1 次（即第十三条第（四）项），唯一可引的不预交依据是第二十条第一款末句，且主体限缩为「追索劳动报酬的案件」、措辞是「可以」 |
| 尚未核实 | 该办法的「现行有效」标注未在国家法律法规数据库逐字确认（flk 正文为 OFD 图片、无可读文字层）；本报告只确认了中国政府网两个官方页 + 两处转载全文在线可取。**注意**：《仲裁法》已于 2025-09-12 公布新修正、2026-03-01 施行，那是**商事仲裁**法，与本书用的劳动争议仲裁无关，正文中切勿混用名称 |

## 关于 flk.npc.gov.cn 的工具性结论

国家法律法规数据库的详情页正文由 OFD 图片阅读器（`flkofd.npc.gov.cn/reader`）渲染，**没有文字层**，`/reader/text` 接口只返回页面几何参数。因此 flk 只能用来确认「公布日期 / 施行日期 / 是否有效 / 有无修订」这类元数据，**逐字原文必须另找全国人大网、中国政府网、国务院公报或省级以上官方转载页**。凡本记录里出现 flk 链接的，作用都只是时效性旁证。

另记两条抓取约束：**WebFetch 的逐字摘录会被截断到 125 字左右**，长条款要用 `curl` 取回本地再去标签；gov.cn 的 URL **不能猜**，猜过两次都是 404，必须从搜索结果里拿现成地址。

## 第 5 节 不要浪费钱

### 5-2 长对话、重复前缀的活，开提示缓存

| 项 | 内容 |
| --- | --- |
| 口径 | 厂商定价**只认厂商自己的文档页**，媒体转述与第三方博客一律不算来源；且必须记抓取日期，因为定价随时改 |
| 抓取方式 | 本机 `curl` 直连被区域拦截（`claude.com/app-unavailable-in-region`、openai.com 403、ai.google.dev 连接失败），改用本地浏览器实际打开页面后取 `document.body.innerText`。**因此本页数字的独立复核必须在另一台网络环境下重做一遍** |
| 断言（Anthropic） | 缓存读取 = 基础输入价 0.1 倍；5 分钟写 = 1.25 倍；1 小时写 = 2 倍；默认 5 分钟有效、命中免费续期；最短可缓存长度按模型 512 / 1,024 / 2,048 / 4,096 token |
| 抓取页 | <https://platform.claude.com/docs/en/build-with-claude/prompt-caching>（访问 2026-09-20） |
| 逐字摘录 | 「5-minute cache write tokens are 1.25 times the base input tokens price」「1-hour cache write tokens are 2 times the base input tokens price」「Cache read tokens are 0.1 times the base input tokens price」「By default, the cache has a 5-minute lifetime. | 断言（OpenAI） | 支持模型默认开启；复用 token 走折扣价，**表述为上限**「discounted up to 90%」；写缓存不是额外加价 |

There is nothing you need to do in order to enable this.」＋表「Model / Min token limit：Gemini 3.8 Flash 4,096 … Gemini 2.5 Flash 2,048、Gemini 2.5 Pro 2,048」 |

## 文献类条目的核验口径（第 1、2、9、10 节的论文出处）

论文出处的 A 级门槛比法条低一档，所以规矩要更硬：**必须实际打开 `arxiv.org/abs/<编号>` 或 DOI 落地页，摘录只能抄摘要页上看得见的那句原话**。摘要页没有效应量数字的，一律降到 B 级并写明「只有方向、没有量级」。

- 摘要页与全文页要分开标：从 `arxiv.org/html/<编号>` 取到的句子属于**全文页**，样本量、细分口径常在那里，引用时注明不是摘要页。
- **未通过核验、禁止挂数字的**：MIT「95% 的 GenAI 试点失败」——第一方页面未能打开并逐字核到，网上只有媒体与镜像 PDF；Noy & Zhang（*Science*, DOI 10.1126/science.adh2586）的「时间 -40%、质量 +18%」——DOI 落地页 403，数字来自 Crossref 里出版社自存的摘要元数据，**须人工在浏览器打开原文确认后才能用**，且其 SSRN 早期版本口径不同（444 人、0.8 SD / 0.4 SD），两个版本禁止混引。
- 摘要页只有样本量没有效应量的（可作 B 级定性引用）：arXiv 2603.04537（378 名职业视觉艺术家自述）、arXiv 2602.08955（Lyft 4,700 万单行程的准实验，方向为正、量级未量化）。
- 明确建议不用的「写作类接单收入下降 x%」类：Hui/Reshef/Zhou（Organization Science, 10.1287/orsc.2023.18441）、arXiv 2308.05201、Cohen 等《When AI Sets Wages》（SSRN/DOI 落地页打不开）——**摘要页里根本没有百分比**，凡见到带数字的转述都是二手加工。
