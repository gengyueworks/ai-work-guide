# 来源核实记录

这本指南的信用全押在一件事上：**「来源」栏写的东西，读者点进去能看到那句原文**。这份记录就是那条链路的外账——每条 A 级条目在这里有一行，写明我们**实际抓取过**的页面、抓取日期，以及页面上的原句。

三条规矩：

1. **只记抓到的，不记记忆的。** 没在页面上亲眼看到的条号、比例、金额，一律不进正文；进了正文的必须能在本页找到对应行。
2. **摘录必须是逐字。** 媒体转述、博客总结、模型记忆都不算来源。英文文献抄原句，法条抄条款全文。
3. **核不上就降级，不硬撑。** 来源栏写「待核实」不是失败，写一个想当然的条号才是。

### 8-1 先分清你是被裁还是被辞退：N、N+1、2N 各对应哪一种

| 项 | 内容 |
| --- | --- |
| 断言 | 分档口径（每满一年一个月／六个月以上不满一年按一年／不满六个月半个月）；「+1」只挂第四十条且与 N 并存；违法解除为二倍；2N 与 N 不叠加 |
| 出处 | 第四十条、第四十六条第（二）（三）（四）项、第四十七条第一款、第八十七条；实施条例第二十五条 |
| 逐字摘录 | 见「共用来源块」所列 S2 页抽出结果，关键三句：「第四十七条 经济补偿按劳动者在本单位工作的年限，每满一年支付一个月工资的标准向劳动者支付。六个月以上不满一年的，按一年计算；不满六个月的，向劳动者支付半个月工资的经济补偿。」「第八十七条 用人单位违反本法规定解除或者终止劳动合同的，应当依照本法第四十七条规定的经济补偿标准的二倍向劳动者支付赔偿金。」「第二十五条 用人单位违反劳动合同法的规定解除或者终止劳动合同，依照劳动合同法第八十七条的规定支付了赔偿金的，不再支付经济补偿。赔偿金的计算年限自用工之日起计算。」 |
| 编者改正 | 草稿原写「公司没提前三十天书面通知就让你走，多加的那一个月就是 +1」——**不成立**。全法检索「额外支付」只出现 1 次（第四十条），第四十一条经济性裁员通篇无此表述；且它是「提前三十日书面通知」**或**「额外支付一个月工资」二选一，不是默认要付。人社部发〔2008〕78号《〈劳动合同法实施条例〉宣传提纲》<https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=504> 亦写明代通知金只挂第四十条 |
| 「N+1」用词 | 三个官方全文里「N+1」「N＋1」出现次数均为 **0**，确认是俗称；上海人社局答复也按俗称解释，且明确代通知金与提前三十日通知是二选一、代通知金不替代经济补偿 <https://rsj.sh.gov.cn/trdhy_17355/20250909/t0035_1435421.html> |

### 8-2 「月工资」有上限，也有下限：别拿税前月薪直接乘

| 项 | 内容 |
| --- | --- |
| 断言 | 算经济补偿用的月工资是**应得工资**（含奖金、津贴），不是实发工资；低于当地最低工资标准的按最低工资算；工作不满 12 个月的按实际月数算平均 |
| 出处 | 《中华人民共和国劳动合同法实施条例》（国务院令第 535 号，2008-09-18 公布）第二十七条，共 3 款；封顶规则在《劳动合同法》第四十七条第二款、第三款 |

| 访问日期 | 2026-09-20 |
| 逐字摘录 | 「劳动合同法第四十七条规定的经济补偿的月工资按照劳动者应得工资计算，包括计时工资或者计件工资以及奖金、津贴和补贴等货币性收入。劳动者在劳动合同解除或者终止前12个月的平均工资低于当地最低工资标准的，按照当地最低工资标准计算。劳动者工作不满12个月的，按照实际工作的月数计算平均工资。」「第四十七条 第二款 劳动者月工资高于用人单位所在直辖市、设区的市级人民政府公布的本地区上年度职工月平均工资三倍的，向其支付经济补偿的标准按职工月平均工资三倍的数额支付，向其支付经济补偿的年限最高不超过十二年。第三款 本条所称月工资是指劳动者在劳动合同解除或者终止前十二个月的平均工资。」 |

## 关于 flk.npc.gov.cn 的工具性结论

国家法律法规数据库的详情页正文由 OFD 图片阅读器（`flkofd.npc.gov.cn/reader`）渲染，**没有文字层**，`/reader/text` 接口只返回页面几何参数。因此 flk 只能用来确认「公布日期 / 施行日期 / 是否有效 / 有无修订」这类元数据，**逐字原文必须另找全国人大网、中国政府网、国务院公报或省级以上官方转载页**。凡本记录里出现 flk 链接的，作用都只是时效性旁证。

## 文献类条目的核验口径（第 1、3、6、14、17 节的论文出处）

论文出处的 A 级门槛比法条低一档，所以规矩要更硬：**必须实际打开 `arxiv.org/abs/<编号>` 或 DOI 落地页，摘录只能抄摘要页上看得见的那句原话**。摘要页没有效应量数字的，一律降到 B 级并写明「只有方向、没有量级」。

- **预印本先查有没有刊发版，两版数字可能不一样**。arXiv 页没有 Comments／Journal-ref 时只能到 B，但这不等于这篇没发表：**NBER 的作者页自带「Published Versions」栏，会逐字写出期刊名、卷期、页码**，那是第一方页面、不是媒体转述，够 A 级门槛（首例见「1-7 从 B 升 A」一节：同一篇 *Generative AI at Work*，arXiv 摘要写 5,172 人 +15%，刊发版摘要写 5,179 人 +14%、并新增新手 +34% 与资深者「minimal impact」）。**采用刊发版数字，同时把预印本的旧数字写进来源**，因为网上转述大多还是预印本那一组，读者会两个都看到。
- 同一页面内部的**摘要栏与「In Brief／要点」栏不是一回事**：要点栏常是被编辑过的截断文本（NBER 那页要点写 35%、摘要写 34%）。**只引 Abstract**，并在备注里说明为什么不用另一栏。
- 摘要页与全文页要分开标：从 `arxiv.org/html/<编号>` 取到的句子属于**全文页**，样本量、细分口径常在那里，引用时注明不是摘要页。
- **未通过核验、禁止挂数字的**：MIT「95% 的 GenAI 试点失败」——第一方页面未能打开并逐字核到，网上只有媒体与镜像 PDF；Noy & Zhang（*Science*, DOI 10.1126/science.adh2586）的「时间 -40%、质量 +18%」——DOI 落地页 403，数字来自 Crossref 里出版社自存的摘要元数据，**须人工在浏览器打开原文确认后才能用**，且其 SSRN 早期版本口径不同（444 人、0.8 SD / 0.4 SD），两个版本禁止混引。
- 摘要页只有样本量没有效应量的（可作 B 级定性引用）：arXiv 2603.04537（378 名职业视觉艺术家自述）、arXiv 2602.08955（Lyft 4,700 万单行程的准实验，方向为正、量级未量化）。
- 明确建议不用的「写作类接单收入下降 x%」类：Hui/Reshef/Zhou（Organization Science, 10.1287/orsc.2023.18441）、arXiv 2308.05201、Cohen 等《When AI Sets Wages》（SSRN/DOI 落地页打不开）——**摘要页里根本没有百分比**，凡见到带数字的转述都是二手加工。

## 出处链接的可点开性（2026-09-21 全站审计）

「来源」栏写得再全，链接点不开就等于没有。这次把网页实际渲染出来的 href 全量拉出来和正文比对，结论是**修复前 173 个 `<a>` 里 108 个是死链**——80 条出处链接无一幸免。

- 根因：正文一律把链接写成 markdown 自动链接 `<https://…>`（72 条），另 8 条裸 URL 后面紧跟 `」`。`linkify()` 先跑 `esc()`，尖括号变成 `&lt;/&gt;`，随后切 URL 的正则只排除空白和 `<`，于是把 `&gt;（访问 2026-09-20，HTTP 200……` 整段吞进 href。点出去是 404，而**门禁当时全绿**：`check-refs` 只管交叉引用，构建只管字段齐不齐。
- 修法：`unwrap()` 先在原文上拆掉 `<>` 包裹，`URL_T` 的字符类补上 `（）「」《》` 等中日韩标点和 `>`，`trimURL()` 去掉尾部 `.,;:`。修复后同一份语料渲染出的 117 个外链 href 与正文里的 URL **逐字相等，异常 0 条**。
- 补的门禁：`tools/lib/book.mjs` 的 `checkLinks()` 用与浏览器**同一套**正则重切一遍，凡「正文里的 URL」与「网页会切出的 href」不一致、或切出的 href 里含中文，一律算结构问题、`--check` 退出码 1。已反向验证它确实会失败：URL 内含中文括号（被截断）、裸 URL 后无标点直接接中文（把正文吞进 href）两种写法都被拦下。
- 抽样回访（浏览器 UA、`curl -L`，2026-09-21）：`arxiv.org/abs/2502.05167` 200、`shanghai.chinatax.gov.cn/…/t443504.html` 200、`rsj.beijing.gov.cn/…/t20191207_951033.html` 200、`rlsbj.cq.gov.cn/…/t20210305_8968497.html` 200、`microsoft.com/…/lee_2025_ai_critical_thinking_survey.pdf` 200；`doi.org/10.1145/3706598.3713778` **403**（ACM 拦非浏览器，正文备注里早已声明逐字来源是作者自存档的 CC-BY PDF，不影响该条等级）；`gongbao.court.gov.cn/Details/997e…html` 本次 **502**，而 2026-09-20 用同一 UA 取到过 27,022 字节全文，判为服务端抖动，列入待补重测。
