# 5. 不要浪费钱

本节口径是金钱：AI 相关的订阅、算力、API 与课程支出。每条写清一个月或一年实际花多少、换回什么。数字凡标 `（待核实：…）` 的都是占位，等抓取管线从厂商定价页回填，**不要当结论**；定价随时改，以官方文档当日版本为准。

七条分两层。**第 1~4 条是「自己怎么少花」**：第 2 条和第 4 条有可逐字点开的厂商文档与国务院文件，第 1 条和第 3 条仍是作者判断（写明了无可引出处）。**第 5~7 条是「已经花出去的那笔，法律给了你哪些抓手」**，跨三个层级：一部法律——《消费者权益保护法》（**现行文本为 2013 年修正版**，第六十三条之后仍写「本法自1994年1月1日起施行。」）；一部行政法规——《消费者权益保护法实施条例》（**国务院令第 778 号，2024 年 2 月 23 日国务院第 26 次常务会议通过，2024 年 3 月 15 日公布，自 2024 年 7 月 1 日起施行**，共 53 条）；一部部门规章——《网络交易平台规则监督管理办法》（**2025 年 12 月 18 日国家市场监督管理总局、国家互联网信息办公室令第 116 号公布，自 2026 年 2 月 1 日起施行**，共 47 条）。**三部都取了多个互不隶属系统的全文页逐条比过**：消保法在深圳、上海两地市场监管局页与商务部「全球法规网」页上**前 62 条逐字符一致**，实施条例在司法部国家行政法规库与生态环境部转发页上**前 52 条逐字符一致**，116 号令在中国网信网与商务部「全球法规网」页上**前 46 条逐字符一致**——三处唯一对不上的都是**最后一条**，差异从施行日期那句话之后才开始，是各网站自己的页脚与附件标记。比对与抓取记录在《来源核实记录》。

三点先说在前面：一，**这些条文写的是经营者应当做什么，不是任何人的退款保证**，能不能退、退多少由监管部门和法院认定；二，**「七天无理由退货」那一条的原文管的是「销售商品」**，你订的 AI 会员和年卡算不算商品，本指南不作答；三，**116 号令只管「网络交易平台经营者」**，你直接在某家模型服务商官网站付的订阅是不是平台内交易，本节同样不作答。第 5 节第 5 条（自动续费扣你那一笔之前）里那句「提前五天提示」的部门规章本次**没有取到可抓的官方全文页**，它按省级市场监管部门官方问答页的逐字转引采信，是全节唯一一处这样处理，读者按此打折。

### 1. 先把 API 用量按「哪个调用最贵」排出来，再决定省哪儿
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=中 口径=钱 -->
- 成本：0 元；十几分钟看账单
- 说人话：多数人的账单是一两个高频调用吃掉大头，而不是到处零散花钱。先按调用看花了多少，再动手；凭感觉关小参数、换便宜模型，常常省不下钱还把结果弄差。
- 收益：定位到集中支出后，单次优化的效果通常比全面紧缩大（待核实：需要给出「前 N 个调用占账单比例」的实测分布）（全国）
- 证据等级：C（作者自己的判断，无可引出处）
- 来源：作者经验；具体用量看各家控制台账单页，本条不引第三方数字
- 备注：这条的收益量级只算「中」，因为省多少完全取决于你原来的浪费有多大——这正是本指南把性价比和证据等级分开标的原因。

### 2. 长对话、重复前缀的活，开提示缓存
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=大 口径=钱 适合=程序员|产品 -->
- 成本：0 元；改一次请求参数，几行代码
- 说人话：每次请求都把同一份长前缀重发一遍，等于同一段话付好几次钱。开缓存后，命中那部分的单价直接砍到一成——但前提是你的前缀够长，厂商设了起步线，短到不够长的根本不给缓存，所以反复带同一份长文档、长系统提示的活最划算，短问答收益为零。还有一个坑：缓存会过期，你要按你的请求间隔选档，不然写了缓存没读到，只付了写缓存的溢价。
- 收益：命中缓存的重复 token 单价按 Anthropic 文档为**基础输入价的 0.1 倍**（写缓存：5 分钟档 1.25 倍、1 小时档 2 倍；最短可缓存长度按模型 512 / 1024 / 2048 / 4096 token 不等；默认 5 分钟有效，每次命中免费续期）；OpenAI 为**默认开启**、复用 token 走折扣价**最高约 90%**（最短可缓存前缀其文档给出的一档是 1,024 可见输入 token，另两档写「随请求设置变化」）；Google Gemini 2.5 及更新模型**隐式缓存默认开启**、最短输入 2,048（2.5 Flash/Pro）到 4,096（3.5 Flash 等）token，具体折扣比例其定价页当日未列明（待核实：Gemini 的 cached-input 折扣率需在厂商定价页找到明确数字后回填）（全国）
- 证据等级：A（原文逐字核到）
- 来源：只认厂商自己文档页的当日原文，三处均于 2026-09-20 抓取。① Anthropic《Prompt caching》<https://platform.claude.com/docs/en/build-with-claude/prompt-caching>，逐字：「5-minute cache write tokens are 1.25 times the base input tokens price」「1-hour cache write tokens are 2 times the base input tokens price」「Cache read tokens are 0.1 times the base input tokens price」「By default, the cache has a 5-minute lifetime. The cache is refreshed for no additional cost each time the cached content is used.」「the minimum cacheable prompt length is: 512 tokens … 1,024 tokens … 2,048 tokens … 4,096 tokens」；② OpenAI《Prompt caching》<https://platform.openai.com/docs/guides/prompt-caching>（实际渲染地址 developers.openai.com/api/docs/guides/prompt-caching），逐字：「Cheaper input tokens: Pay the model's reduced cached-input rate for reused tokens, discounted up to 90%」「Prompt caching is enabled by default for supported OpenAI models」「Cache-write pricing is not an additive fee」；③ Google《Context caching》<https://ai.google.dev/gemini-api/docs/caching>，逐字：「Implicit caching is enabled by default for all Gemini 2.5 and newer models」「We automatically pass on cost savings if your request hits caches」
- 备注：三家的口径不是一回事，别当成同一个数字：Anthropic 给的是**确定倍数**，OpenAI 给的是**上限**（「up to 90%」，不是每档都九折），Google 只说**默认返还节省**而当日页面没写比例。判定条件仍然优先于数字——请求间没有长且重复的前缀时收益为零，别为了开缓存改坏现有提示词结构。定价随时改，本页数字过期就得重抓，账号在不同平台（Bedrock / Vertex / Google Cloud）的可用性和价格也可能不同。

### 3. 别为「可能用得上」同时订多份全家桶
<!-- 成本标签: 钱=多 时间=少 毅力=是 收益=小 口径=钱 -->
- 成本：多份订阅叠加，每月数百元起；同时维护多套使用习惯要长期对抗惯性
- 说人话：不同产品的强项错开，但多数人 90% 的活落在一个工具上。同时订三份，省下的切换时间不值那份钱，还会因为每个都用不深而高估自己的产出。
- 收益：每份冗余订阅即每月纯支出（待核实：需要用量分布数据支撑「90% 落在一个工具」这句，目前是本指南作者观察，不足以外推）（全国）
- 证据等级：C（作者自己的判断，无可引出处）
- 来源：作者判断，无直接文献
- 备注：反向也成立——只在一个生态里加深绑定有议价与安全成本，见第 17 节第 3 条（别把全部生产资料绑在一个账号或一家生态上）。

### 4. 考下职业资格证书的那一年，可以少计 3600 元应税收入——但别把它读成「退你 3600 元」
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=中 口径=钱 适合=在职员工|应届生|自由职业与接单|在校学生 -->
- 成本：0 元；在个税 APP 里填一次，几分钟
- 说人话：这是全书最容易被转错的一个数字。**3600 元不是退给你的钱，是从你的应税收入里扣掉的额度**——你实际少交的是 3600 乘以你的边际税率：税率 3% 的人少交 108 元，10% 的人少交 360 元，20% 的人 720 元。所以它值得填，但**不值得为它去考证**。三条容易漏的：**一，只能按「取得证书的当年」扣，过期不补**；**二，你考的证必须在人社部发布的《国家职业资格目录》里**，目录外的培训结业证、协会发的"能力证书"不算（这一条正是第 15 节里那句「重点核查批量持外省份同一评价机构证书」在防的东西）；**三，如果你同时在读学历继续教育（每月 400 元、全年 4800 元），两者可以叠加**，税务局的口径写得很明确：同年既在读学历继续教育又拿到职业资格证书，该年度合计可扣 **8400 元（4800＋3600）**，但**只能各享受一个**，不能拿两本职业证书叠两份 3600。
- 收益：全国口径的现行规则（**扣除额，非现金补贴**）：纳税人接受**技能人员职业资格继续教育、专业技术人员职业资格继续教育**的支出，**在取得相关证书的当年按 3600 元定额扣除**；**学历（学位）继续教育按每月 400 元定额扣除，同一学历扣除期限不超过 48 个月**（48 个月含因病或非主观原因休学且学籍保留的期间、以及施教机构按规定组织的寒暑假，连续计算）；范围依据**人社部发布的《国家职业资格目录》**；学历与职业资格**同年可叠加，合计 8400 元（4800＋3600），但只能同时享受一个学历继续教育加一个职业资格继续教育**；申报时须填报**证书名称、证书编号、发证机关、发证（批准）时间**，并**留存职业资格相关证书等资料备查**
- 证据等级：A（原文逐字核到）
- 来源：① 《国务院关于印发〈个人所得税专项附加扣除暂行办法〉的通知》（**国发〔2018〕41号**，页面元数据逐字：文号「国发〔2018〕41号」、发文单位「国务院」、发文日期「2018-12-13」、状态「全文有效」）**第八条**逐字：「纳税人在中国境内接受学历（学位）继续教育的支出，在学历（学位）教育期间按照每月400元定额扣除。同一学历（学位）继续教育的扣除期限不能超过48个月。纳税人接受技能人员职业资格继续教育、专业技术人员职业资格继续教育的支出，在取得相关证书的当年，按照3600元定额扣除。」全文页：国家税务总局上海市税务局政策法规库 <http://shanghai.chinatax.gov.cn/zcfw/zcfgk/grsds/201901/t443504.html>（访问 2026-09-20，HTTP 200，39,664 字节）。② **逐字交叉比对**：国家税务总局天津市税务局热点问答 <https://tianjin.chinatax.gov.cn/11200000000/0300/030005/20211228154438900.shtml>（访问 2026-09-20，HTTP 200，33,163 字节）原文转引第八、九、十条，与①**逐字符一致**。③ 现行操作口径取自国家税务总局上海市税务局《继续教育专项附加扣除热点问答》（**发布 2026-02-26**）<https://shanghai.chinatax.gov.cn/zcfw/rdwd/202602/t479530.html>（访问 2026-09-20，HTTP 200，39,003 字节），逐字：「技能人员职业资格继续教育、专业技术人员职业资格继续教育请参照人力资源和社会保障部门发布的《国家职业资格目录》。」「纳税人接受学历继续教育，可以按照每月400元的标准扣除，全年共计4800元；在同年又取得技能人员职业资格证书或者专业技术人员职业资格证书的，且符合扣除条件的，可按照3600元的标准定额扣除。但是，只能同时享受一个学历（学位）继续教育和一个职业资格继续教育。因此，对同时符合此类情形的纳税人，该年度可叠加享受两个扣除，当年其继续教育共计可扣除8400元（4800+3600）。」该页并逐字引用**现行**操作办法为《国家税务总局关于修订发布〈个人所得税专项附加扣除操作办法（试行）〉的公告》（**国家税务总局公告〔2022〕7号**）第三条、第十三条
- 备注：**边际税率那一层的换算（108／360／720 元）是本指南按现行税率表做的算术，不是文件原句**，文件只给「3600 元定额扣除」——把它当现金补贴来传是本条见过最高频的错误。三点边界：一，**《国家职业资格目录》本身的具体清单未取到可引全文页，本条不列举任何证书名称**，请以人社部公布的目录为准，别按证书名字猜；二，天津页（2021-12-28）引的操作办法文号是**国家税务总局公告 2018 年第 60 号**，上海页（2026-02-26）引的是**〔2022〕7号修订版**，两页第三、十三条文字逐字相同，本条按**修订版**标注现行有效，但**未逐条比对两版全文差异**；三，扣除方式（综合所得年度自行申报时汇算，或由单位按月预扣时扣）与所需材料的细则未展开。**与第 15 节第 1 条（先去查你手上那张证书）是同一本证的两笔钱**：那边是从失业保险基金领的现金补贴，这边是应税收入里扣掉的额度，**两者互不排斥、可同时成立**。
### 5. 自动续费扣你那一笔之前，法律要求它先打招呼；你买下的会员服务，它也不能改了规则就减你的权益
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=大 口径=钱 适合=程序员|产品|在职员工|管理者|学生与应届生|自由职业与接单|文案与自媒体 -->
- 成本：0 元；一次去账户里核订阅、一次开口要退费的动作
- 说人话：「这个月怎么又被扣了一笔」是这本书里最普遍的一笔浪费，而管它的文件有两层，**层级不一样，能给的力度也不一样**。**第一层是行政法规**：《消费者权益保护法实施条例》第十条（141 字）第二款逐字「经营者采取自动展期、自动续费等方式提供服务的，应当在消费者接受服务前和自动展期、自动续费等日期前，以显著方式提请消费者注意。」**这句话只要求「显著提请」，没有要求提前几天**。更具体那句在部门规章里：《网络交易监督管理办法》第十八条要求「在消费者接受服务前和自动展期、自动续费等日期**前五日**」提请注意，并且「在服务期间内，应当为消费者提供显著、简便的随时取消或者变更的选项，并不得收取不合理费用」——**但这一条本次没有取到该办法的官方全文页**（详见来源栏第三段），所以「五天」这个数按省级市场监管部门官方问答页的逐字转引采信，**读者按此打折**。**第二层是 2026 年 2 月 1 日起施行的《网络交易平台规则监督管理办法》**（**2025 年 12 月 18 日国家市场监督管理总局、国家互联网信息办公室令第 116 号公布**），它把「改规矩」这件事的程序写死了：第十二条（85 字）「网络交易平台经营者制定、修改的平台规则，应当至少在实施前七日予以公示。对于涉及用户数量巨大、修改内容较多、关系有关各方重要权益的平台规则，应当至少在实施前十五日予以公示。」第十三条（95 字）要求按影响程度**设置合理的过渡期**；第十六条（86 字）「网络交易平台经营者不得强制或者诱导经营者和消费者对相关平台规则表示同意，不得将相关平台规则设定为默认同意的选项，但不增加经营者和消费者义务、不减损经营者和消费者权益的除外」；第三十一条（61 字）「网络交易平台经营者不得利用平台规则，在消费者不知情的情况下，对同一商品或者服务在同等交易条件下设置不同的价格或者收费标准。」——**这句的后半句和《实施条例》第九条第二款逐字相同，一个管平台、一个管所有经营者**。**而第三十二条（198 字）是专门写给会员制的**：「消费者购买网络交易平台经营者提供的会员服务的，网络交易平台经营者不得在约定服务期内通过单方面修改平台规则的方式，擅自收取额外费用或者减损会员权益。在消费者继续购买会员服务前，网络交易平台经营者应当以显著方式告知消费者平台规则中与会员权益相关的变化情况。」**最实用的是第十四条（145 字）那两句**：「平台内经营者、消费者不接受平台规则修改的内容，要求退出平台或者终止相关服务的，网络交易平台经营者不得以设置不合理条件等方式阻止。」「网络交易平台经营者应当按照修改前的平台规则承担据实退还费用等相关责任，不得故意拖延或者无理拒绝。」**连起来读就是一条动作链：改规则要提前公示 → 你不同意可以走 → 走了它得按老规矩把钱据实退给你 → 不许拖、不许拒。**
- 收益：全国口径的六项义务加两项后果：①**自动展期、自动续费须在消费者接受服务前和续费日期前以显著方式提请注意**（行政法规层，**没有规定天数**）；②平台规则**实施前至少 7 日公示**，涉及用户数量巨大、修改内容较多、关系有关各方重要权益的**至少 15 日**，并**按影响程度设置合理过渡期**；③**不接受修改可要求退出平台或终止服务，平台不得以设置不合理条件阻止，且应按修改前的平台规则承担据实退还费用等责任，不得故意拖延或者无理拒绝**；④**不得强制或诱导同意，不得把平台规则设为默认同意的选项**；⑤**会员服务在约定服务期内不得擅自加收额外费用或减损会员权益**，在你继续购买前须以显著方式告知与会员权益相关的规则变化；⑥**不得利用平台规则在你不知情时设置不同价格或收费标准**（差别定价那一档）。后果：**违反第三十二条第一款等情形，由市场监督管理部门责令限期改正，可以处一万元以上十万元以下罚款**（第四十条，142 字）；**处罚决定应当依法通过国家企业信用信息公示系统向社会公示**（第四十五条，57 字）；**违反《实施条例》第十条的，可处违法所得 1 倍以上 5 倍以下罚款，没有违法所得的处 30 万元以下罚款，情节严重的责令停业整顿、吊销营业执照**（《实施条例》第五十条，339 字）（全国）

### 6. 「虚拟商品概不退款」这句话的效力，比它看起来小得多——但线上买的数字化商品确实有一条明文除外
<!-- 成本标签: 钱=0 时间=少 毅力=些 收益=大 口径=钱 适合=程序员|产品|在职员工|学生与应届生|自由职业与接单|文案与自媒体|管理者 -->
- 成本：0 元；一次购买页的截图留存，加一次开口
- 说人话：先给一句容易传错的话：**七天无理由退货不是万能抓手，它在法条里管的是「销售商品」。**《消费者权益保护法》第二十五条（243 字）逐字「经营者采用网络、电视、电话、邮购等方式销售商品，消费者有权自收到商品之日起七日内退货，且无需说明理由，但下列商品除外：（一）消费者定作的；（二）鲜活易腐的；（三）在线下载或者消费者拆封的音像制品、计算机软件等数字化商品；（四）交付的报纸、期刊。」**第三项就是那句「数字商品不退」的出处**，它写得很宽。但同一条紧接着还有一句常被省略的：「除前款所列商品外，其他根据商品性质并经消费者在购买时确认不宜退货的商品，不适用无理由退货。」——**注意「并经消费者在购买时确认」这几字（原文作「其他根据商品性质并经消费者在购买时确认不宜退货的商品，不适用无理由退货」），它不是一句店堂告示就能把商品划进例外。**《消费者权益保护法实施条例》第十九条（274 字）把这一句变成了可执行的三道手续：「经营者通过网络、电视、电话、邮购等方式销售商品的，应当遵守消费者权益保护法第二十五条规定，不得擅自扩大不适用无理由退货的商品范围。」「经营者应当以显著方式对不适用无理由退货的商品进行标注，提示消费者在购买时进行确认，**不得将不适用无理由退货作为消费者默认同意的选项。未经消费者确认，经营者不得拒绝无理由退货。**」还有一句专治「拆封＝不退」：「消费者基于查验需要打开商品包装，或者为确认商品的品质和功能进行合理调试而不影响商品原有品质、功能和外观的，经营者应当予以退货。」**第二层是那句「概不退款」本身的效力**：《消费者权益保护法》第二十六条（236 字）要求经营者以显著方式提请消费者注意「商品或者服务的数量和质量、价款或者费用、履行期限和方式、安全注意事项和风险警示、售后服务、民事责任等与消费者有重大利害关系的内容」，并写着「经营者不得以格式条款、通知、声明、店堂告示等方式，作出排除或者限制消费者权利、减轻或者免除经营者责任、加重消费者责任等对消费者不公平、不合理的规定，不得利用格式条款并借助技术手段强制交易。**格式条款、通知、声明、店堂告示等含有前款所列内容的，其内容无效。**」《实施条例》第十七条（116 字）再补一刀，逐字「经营者使用格式条款的，应当遵守消费者权益保护法第二十六条的规定。经营者不得利用格式条款不合理地免除或者减轻其责任、加重消费者的责任或者限制消费者依法变更或者解除合同、选择诉讼或者仲裁解决消费争议、选择其他经营者的商品或者服务等权利。」**第三层才是付了钱、东西没给到位时的抓手**：《实施条例》第二十二条（316 字）四句连读——「经营者以收取预付款方式提供商品或者服务的，应当与消费者订立书面合同，约定商品或者服务的具体内容、价款或者费用、预付款退还方式、违约责任等事项。」「经营者收取预付款后，应当按照与消费者的约定提供商品或者服务，不得降低商品或者服务质量，不得任意加价。」「经营者未按照约定提供商品或者服务的，应当按照消费者的要求履行约定或者退还预付款。」「经营者出现重大经营风险，有可能影响经营者按照合同约定或者交易习惯正常提供商品或者服务的，应当停止收取预付款。」末两句还写着停业迁移「应当提前告知消费者，并履行本条例第二十一条规定的义务」，以及**「消费者依照国家有关规定或者合同约定，有权要求经营者继续履行提供商品或者服务的义务，或者要求退还未消费的预付款余额」**；而第二十一条（60 字）把「提前」给了天数：**「经营者决定停业或者迁移服务场所的，应当提前30日在其经营场所、网站、网店首页等的醒目位置公告经营者的有效联系方式等信息。」**
- 收益：全国口径三层：①**网络等方式销售商品七日内可无理由退货**，法定除外只有四项（定作、鲜活易腐、**在线下载或者消费者拆封的音像制品、计算机软件等数字化商品**、报纸期刊），**其余按商品性质不宜退货的商品，必须经消费者在购买时确认**；②**不得擅自扩大不适用无理由退货的商品范围**，须**显著标注**并提示确认、**不得设为默认同意**，**未经确认不得拒绝无理由退货**，且**为查验而打开包装、为确认品质和功能合理调试而不影响原有品质功能外观的应当退货**；③**格式条款、通知、声明、店堂告示含有排除限制消费者权利、减轻免除经营者责任、加重消费者责任等内容的，其内容无效**；**不得利用格式条款限制消费者依法变更或解除合同、选择诉讼或仲裁、选择其他经营者的商品或服务等权利**；④**预付款须订立书面合同并约定退还方式与违约责任**，**不按约定提供商品或服务的应按消费者要求履行约定或退还预付款**，**出现重大经营风险应当停止收取预付款**，**停业或迁移应提前 30 日醒目公告有效联系方式**，**消费者可要求退还未消费的预付款余额**；⑤商品或服务**不符合质量要求**时另有独立退路：《消费者权益保护法》第二十四条（181 字）「没有国家规定和当事人约定的，消费者可以自收到商品之日起七日内退货」（全国）

- 来源：①《中华人民共和国消费者权益保护法》**第二十四条（181 字）、第二十五条（243 字）、第二十六条（236 字）**，现行文本为**2013 年修正版**，全文页三份：深圳市市场监督管理局政策法规页 <https://amr.sz.gov.cn/xxgk/zcwj/scjgfg/content/post_12816850.html>（访问 2026-09-21，HTTP 200，**57,015 字节**；页面元数据逐字「第二次修正」「2013年10月25日」，文末逐字「转载来源：中国人大网」「转载时间：2013-11-04」）、上海市市场监督管理局法规库 <https://fw.scjgj.sh.gov.cn/alc/law/11/1/20240117133417.html>（访问 2026-09-21，HTTP 200，**28,684 字节**）、商务部「全球法规网」<https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=5018>（访问 2026-09-21，HTTP 200，**38,049 字节**，标题逐字「中华人民共和国消费者权益保护法（2013修正）」）。**三页共 63 条，第一条至第六十二条逐字符一致**，唯一差异在第六十三条（「本法自1994年1月1日起施行。」之后的各自页脚与附件标记）。②《中华人民共和国消费者权益保护法实施条例》**第十二条（102 字）、第十七条（116 字）、第十九条（274 字）、第二十条（87 字）、第二十一条（60 字）、第二十二条（316 字）**：全文页两份，见第 5 节第 5 条（自动续费扣你那一笔之前）来源栏①（国家行政法规库 51,159 字节／生态环境部转发中国政府网文本 65,118 字节，**53 条逐字符一致**）。
- 备注：**这一条要打折的地方最多，逐条说清**：一，**「无理由退货」那一句的主语是「销售商品」**（第二十五条逐字），**你订的 AI 会员、充的年卡算商品还是服务，本条不作答**，这是本节最大的未决问题，任何把它直接读成「AI 订阅都能七天退」的说法都不属于本指南。二，**「在线下载或者消费者拆封的音像制品、计算机软件等数字化商品」这一项怎么覆盖到在线课程、token 充值包、模型订阅，本次没有取到可引的解释性文件**，本条**不做类比**。三，**「其内容无效」不等于钱自动回来**：主张格式条款无效要走投诉、调解或诉讼，**本条不承诺任何结果**。四，**「30日」「7日内」这些天数各自管的事件不同，禁止互相套用**：第二十一条的 30 日是**停业或迁移前的公告期**，第二十四条与第二十五条的七日是**退货期**，《实施条例》第四十六条的 7 个**工作日**是**行政部门处理投诉的时限**（见第 5 节第 7 条（投诉处理有天数））。五，**押金那一条（《实施条例》第二十条，87 字）本节未展开**，它管的是「收取押金」的情形，与订阅不是一回事。与第 6 节第 1 条（不要为「怕错过」买系统性课程包）配套看：那条说**别买**，这条说**已经买了、而且买完发现不合用时，法条给了哪几句可以引用的话**。

### 7. 钱要不回来时有两条法定的路：投诉处理有天数，构成欺诈的有三倍
<!-- 成本标签: 钱=0 时间=多 毅力=些 收益=大 口径=钱 适合=程序员|产品|在职员工|学生与应届生|自由职业与接单|文案与自媒体|管理者 -->
- 成本：0 元；主要是时间与材料整理
- 说人话：多数人为几十块钱的订阅直接放弃，理由是「算了吧，不值得」。但走行政投诉这条路的法定成本是这样写的：《消费者权益保护法实施条例》第二十六条（91 字）逐字「消费者与经营者发生消费者权益争议的，可以向市场监督管理部门或者其他有关行政部门投诉。自然人、法人或者其他组织可以向市场监督管理部门或者其他有关行政部门举报，反映经营者涉嫌违法的线索。」——**注意前半句是「消费者…投诉」，后半句的「举报」任何人皆可，不要求你是受害人。**第四十四条（73 字）要求「经营者应当建立便捷、高效的投诉处理机制，及时解决消费争议」，并「鼓励和引导经营者建立健全首问负责、先行赔付、在线争议解决等制度」。而第四十六条（292 字）给了两个硬数字：「有关行政部门应当自收到投诉之日起7个工作日内，予以处理并告知消费者。对不符合规定的投诉决定不予受理的，应当告知消费者不予受理的理由和其他解决争议的途径。」「有关行政部门受理投诉后，消费者和经营者同意调解的，有关行政部门应当依据职责及时调解，并在受理之日起60日内调解完毕；调解不成的应当终止调解。**调解过程中需要鉴定、检测的，鉴定、检测时间不计算在60日内。**」**另一条路是赔：《消费者权益保护法》第五十五条（207 字）**「经营者提供商品或者服务有欺诈行为的，应当按照消费者的要求增加赔偿其受到的损失，增加赔偿的金额为消费者购买商品的价款或者接受服务的费用的三倍；**增加赔偿的金额不足五百元的，为五百元。**法律另有规定的，依照其规定。」《实施条例》第四十九条（225 字）把这条**两头都收了一下**：一头是除外「但是，商品或者服务的标签标识、说明书、宣传材料等存在不影响商品或者服务质量且不会对消费者造成误导的瑕疵的除外」；另一头是**反向条文**——「通过夹带、掉包、造假、篡改商品生产日期、捏造事实等方式骗取经营者的赔偿或者对经营者进行敲诈勒索的，不适用消费者权益保护法第五十五条第一款的规定，依照《中华人民共和国治安管理处罚法》等有关法律、法规处理；构成犯罪的，依法追究刑事责任。」**监管那一侧的钱**在《消费者权益保护法》第五十六条（622 字）：「由工商行政管理部门或者其他有关行政部门责令改正，可以根据情节单处或者并处警告、没收违法所得、**处以违法所得一倍以上十倍以下的罚款，没有违法所得的，处以五十万元以下的罚款；情节严重的，责令停业整顿、吊销营业执照**」，其列举情形里第（八）项逐字「对消费者提出的修理、重作、更换、退货、补足商品数量、退还货款和服务费用或者赔偿损失的要求，故意拖延或者无理拒绝的」，第（六）项「对商品或者服务作虚假或者引人误解的宣传的」，末句「经营者有前款规定情形的，除依照法律、法规规定予以处罚外，**处罚机关应当记入信用档案，向社会公布**」。
- 收益：全国口径四项：①**向市场监督管理部门或其他有关行政部门投诉**（消费者）／**举报涉嫌违法线索**（任何组织和个人）；②**行政部门应自收到投诉之日起 7 个工作日内处理并告知消费者**，不予受理的须**告知理由和其他解决争议的途径**；受理并同意调解的**应在受理之日起 60 日内调解完毕**，**鉴定、检测时间不计入这 60 日**；③**构成欺诈的，可要求按价款或费用的三倍增加赔偿，不足五百元的按五百元**；④经营者**对退还货款和服务费用等要求故意拖延或无理拒绝**、**作虚假或引人误解的宣传**等十项情形，可被**处违法所得 1 倍以上 10 倍以下罚款，没有违法所得的处 50 万元以下罚款，情节严重的责令停业整顿、吊销营业执照**，且**处罚应当记入信用档案并向社会公布**（全国）

- 备注：**四个必须说清的限制**：一，**三倍赔偿的前提是「欺诈」成立**，是否构成欺诈由行政机关和法院认定，**本条不判断任何具体情形**，也不主张「商家没做到我说的就是欺诈」。二，**天数各管各的**：7 个**工作日**管的是行政部门对投诉的处理告知，60 日管的是调解期限，二者都不是「你几天内必须投诉」；**投诉本身有没有时效，本次未取到可引条文，本条不作答**。三，**「不足五百元的，为五百元」只在欺诈那一档成立**，不能拿它当所有退费的底线。四，**第五十六条的罚款归国库**，不是赔给消费者的钱；它列的十项情形里与 AI 消费最相关的是第（六）项虚假宣传和第（八）项故意拖延退还货款与服务费用，但**引用它不等于这笔钱会进你口袋**。另须提示一条本节所有法律条文共同的边界：**这些文件写的是经营者应当做什么，读者手上具体那笔订阅能不能退、退多少，取决于合同怎么写、服务有没有实际提供、以及监管部门和法院怎么认定，本指南不替任何人判断。**和第 10 节第 7 条（罚则与救济：拒不改正最高）是两套不同的钱：那边是个人信息保护法的罚款档（最高 5000 万元或上一年度营业额 5%），这边是消费争议的罚款档（50 万元以下或违法所得十倍以下），**触发条件和执法机关都不一样，别混着转**。
